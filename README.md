# Portal Layanan Konseling Mahasiswa Universitas Pelita Bangsa (UPB)

Portal konseling psikologi digital resmi untuk mahasiswa Universitas Pelita Bangsa, dikelola oleh **Direktorat Kemahasiswaan dan Alumni (DIRMAWA)**. Layanan ini 100% bebas biaya (free), suportif, dan dijamin kerahasiaannya sesuai Kode Etik Psikologi HIMPSI.

---

## 🌟 Fitur Utama

- **Mode Gelap & Terang (Theme Toggle Slider)**: Tampilan visual modern dengan sakelar *smooth slider* dan palet *Midnight Sky Blue* / *Soft Sky Blue* yang menenangkan batin (*calming UI*).
- **Tes Refleksi & Skrining Psikologi Mandiri**:
  - Skrining Beban Stres Akademik (Adaptasi PSS-10)
  - Skrining Kecemasan & Overthinking (Adaptasi GAD-7)
  - Skrining Kelelahan Studi & Burnout Skripsi (Dimensi MBI Mahasiswa)
  - Kalkulasi skor otomatis privat di sisi browser + fitur salin ringkasan hasil ke clipboard.
- **Alur Pendaftaran Google Form**: Pendaftaran terintegrasi langsung dengan formulir resmi DIRMAWA tanpa hambatan pembuatan akun.
- **Artikel Edukasi Kesehatan Mental Kampus**: Wawasan psikologi praktis tentang regulasi emosi, adaptasi perkuliahan, dan *self-compassion* dengan filter pencarian instan.
- **FAQ Interaktif**: Transparansi alur pendaftaran, jaminan kerahasiaan data mahasiswa, dan kontak darurat 24 jam.
- **Hotline Tanggap Krisis & Tombol Bantuan Cepat**: Akses terpadu ke nomor darurat 119 ext. 8 dan WhatsApp Admin DIRMAWA.

## 🛠️ Teknologi yang Digunakan

- **Frontend**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite 8](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) dengan `@custom-variant dark`
- **Ikon**: [Lucide React](https://lucide.dev/)
- **Tipografi**: *Clash Grotesk* font family

## 🚀 Menjalankan Proyek Secara Lokal

### Prasyarat
- [Node.js](https://nodejs.org/) (versi 18 ke atas)
- [npm](https://www.npmjs.com/)

### Langkah Instalasi
1. Kloning repositori ini:
   ```bash
   git clone https://github.com/username/nama-repo.git
   cd nama-repo
   ```

2. Pasang dependensi:
   ```bash
   npm install
   ```

3. Jalankan server pengembangan lokal:
   ```bash
   npm run dev
   ```
   Aplikasi akan berjalan di `http://localhost:3000/`.

4. Build untuk tahap produksi:
   ```bash
   npm run build
   ```
